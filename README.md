# 👥 Customer Analytics Dashboard

An interactive customer analytics project built with Python and Streamlit to explore customer demographics, income, and spending behaviour.

## 🎯 Project Objectives

- Explore customer demographics.
- Analyse customer age and income.
- Understand spending score patterns.
- Compare customer groups using charts.
- Practise interactive data analysis.

## 🛠️ Technologies Used

- Python
- Pandas
- Streamlit
- Plotly (if used in the application)

## 📂 Project Files

- `app.py` — Main dashboard application.
- `requirements.txt` — Required Python packages.
- Customer dataset — Include the CSV file required by the application.

## ▶️ Run Locally

Install the dependencies:

```bash
pip install -r requirements.txt
```

Launch the dashboard:

```bash
streamlit run app.py
```
